# 📸 RustShot — *ваш экран, пойманный за мгновение!*

> **Один бинарник. Ноль мороки. Скриншоты и запись — как надо.**

RustShot — молниеносная ⚡ утилита для скриншотов и записи экрана,
написанная на Rust 🦀, потому что жизнь слишком коротка для медленных инструментов.

---

## 🌟 Почему RustShot?

| Возможность | Статус | Описание |
|-------------|--------|----------|
| 📷 **Скриншоты** | ✅ Готово | Весь экран или выбранная область |
| 🎬 **Запись экрана** | ✅ Готово | MP4 (H.264) — плавно, как масло 🧈 |
| 🖱️ **Выбор области** | ✅ Готово | Кликнул, потянул — готово! |
| 💾 **Разные форматы** | ✅ Готово | PNG, JPG, BMP — на любой вкус! |
| 🖥️ **Мультимонитор** | ✅ Готово | Три монитора? Не вопрос 😎 |
| ⚡ **Трей-режим** | ✅ Готово | Тихо сидит в трее, как послушная программа |
| 🪟 **Активное окно** | ✅ Готово | Только нужное окно, ничего лишнего |

## 🚀 Как пользоваться

### 🖥️ Трей-режим — *поставил и забыл*

```bash
rustshot
```

Просто запустите. Иконка появится в трее. Дальше — горячие клавиши как у профи:

| 🎹 Горячая клавиша | 🎬 Что произойдёт | 🤔 Когда использовать |
|--------------------|-------------------|----------------------|
| `PrintScreen` | Выбор области → скриншот → буфер обмена 📋 | Когда нужен *именно этот кусочек* |
| `Alt+PrintScreen` | Снимок активного окна → сохранить PNG 🖼️ | Когда всё окно — звезда экрана |
| `Ctrl+Shift+R` | Начать запись 🔴 | Мотор! |
| `Ctrl+Shift+R` ещё раз | Остановить → сохранить MP4 🎬 | Стоп, снято! |
| Правый клик на иконке | Открыть меню 📋 | Для всего остального |

**📂 Куда всё сохраняется?**
| Что | Куда | Зачем |
|-----|------|-------|
| Выбор области | 📋 Только в буфер обмена | Быстро вставить куда надо! |
| Окно и CLI-скриншоты | `Изображения\RustShot\` | Всё по полочкам |
| Записи | `Изображения\RustShot\recordings\` | Вечер кино 🍿 |

> 💡 **Совет:** В Windows трей-режим добавляет себя в автозапуск — RustShot всегда на расстоянии одной горячей клавиши!

### 📸 Примеры CLI — *для воинов командной строки*

#### 1️⃣ Быстрый скриншот
```bash
rustshot --cli
# 📸 *щёлк* — сохранено с автоматическим именем
```

#### 2️⃣ Свой файл
```bash
rustshot --output эпичный_скриншот.png
# 💾 Сохранено именно туда, куда вы хотели
```

#### 3️⃣ Выбрать формат
```bash
rustshot --format jpg --output фото.jpg     # 📷 JPEG — файл поменьше
rustshot --format bmp --output ретро.bmp    # 🖼️ BMP — для ценителей ретро
rustshot --format png --output чёткий.png   # 🎨 PNG — пиксель в пиксель (по умолчанию)
```

#### 4️⃣ Магия мульти-монитора
```bash
rustshot --list              # 👀 Посмотреть все экраны
rustshot --screen 1          # 📺 Снять монитор №2
rustshot --screen 0          # 📺 Снять монитор №1 (нумерация с 0!)
```

#### 5️⃣ Снять активное окно
```bash
rustshot --window            # 🪟 Только текущее окно, ничего лишнего
```

## 📖 Шпаргалка

```text
🎯 ОСНОВНОЕ
  rustshot                         → 🖥️  трей-режим (рекомендуется)
  rustshot --cli                   → 📸  быстрый скриншот
  rustshot --window                → 🪟  активное окно (только Windows)

🎨 СОХРАНЕНИЕ
  rustshot --output file.png       → 💾  сохранить в свой файл
  rustshot --format jpg            → 🖼️  сохранить как JPG

🖥️ ЭКРАНЫ
  rustshot --list                  → 📋  список мониторов
  rustshot --screen 1              → 📺  снять конкретный монитор
```

## ⚙️ Все параметры

```text
    --cli              📸  сделать скриншот и выйти
-w, --window           🪟  снять активное окно (только Windows)
-o, --output <OUTPUT>  💾  имя или путь файла
-f, --format <FORMAT>  🎨  формат: png, jpg, bmp
-s, --screen <SCREEN>  🖥️  номер экрана (с 0)
-l, --list             📋  показать список экранов
-h, --help             ❓  показать помощь
-V, --version          🏷️  показать версию
```
