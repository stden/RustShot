## Constraints

- Do not break existing 420 tests
- Keep single-binary architecture
- Windows remains primary platform
- `screenshots` crate pins `image` to 0.24 — cannot upgrade without migrating to `xcap`

## Risks

| Risk | Mitigation |
|------|-----------|
| Typed errors require touching all modules | Do incrementally, module by module |
| `xcap` migration may break cross-platform | Spike first, test on all CI platforms |
| Scoop package requires external review | Submit early, iterate on feedback |

## Dependencies

- Phase 2 (typed errors) should complete before Phase 3 features
- Phase 1 benchmarks inform Phase 5 regression checks
- Phases 3, 4, 5 can run in parallel
